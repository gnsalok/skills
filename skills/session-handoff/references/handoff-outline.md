# Handoff outline

- Goal and current scope, including user corrections.
- Repository/branch/commit and uncommitted changes; ownership if known.
- Canonical spec, plan, decisions, and relevant code paths.
- Completed work and verification tied to the state tested.
- Current failure or uncertainty, evidence, and experiments already tried.
- External actions completed, their links, and pending access by name only.
- Authorized next actions and actions still outside the requested scope.
- First concrete next step and prerequisites to recheck.

Keep temporary paths labeled as temporary. A subsequent session must check the
current tree and external state rather than replay stale commands blindly.
